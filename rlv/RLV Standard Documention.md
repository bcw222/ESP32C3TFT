# Run Length Video 格式
## 介绍
Run Length Video（RLV）格式是一种为在单片机上播放双色视频而设计的文件格式，具有格式简单，易于解压的特点。它对数据使用游程编码，因而很适合用于存放通常由色块组成的电子视频（而非现实世界录制的视频）。  
## 术语解释
- 单元：数据的最小单元，包含单个游程的颜色和长度。  
## 组成
RLV文件由以下部分组成：
- 头部：包含宽、高、帧率、帧数、单元位宽、帧表位宽等信息。
- 帧表：包含每个帧的起始单元计数信息，用于根据帧号快速定位到相应帧的起始位置。
- 数据：包含每个帧的游程编码数据。
- 填充：为了使文件大小对齐到8字节，可能会有一些填充位，它们应为0。
## 二进制结构
### 头部
头部长6Bytes，由以下数据组成：
- 宽（1Byte）：视频宽度，单位为像素。
- 高（1Byte）：视频高度，单位为像素。
- 帧率（1Byte）：视频帧率，单位为帧每秒。
- 帧数（2Bytes）：视频帧数，单位为帧数。
- 帧表位宽（5Bit）：帧表中每帧索引长度的位宽，单位为位。
- 单元位宽（3Bit）：每个单元除颜色位的位宽，单位为位。为0时将禁用游程编码，每个单元即像素本身。每个单元的位宽为该值加上 1 Bit（颜色位宽）。

例：如下是一个头部的二进制表示：
```
11110000 11110000 00001000 00000111 10000000 10101111
```
其十进制表示为：
```
240 240 8 1920 21 7
```
这表示，该视频的宽为 `240` 像素，高为 `240` 像素，帧率为 `8` 帧每秒，帧数为 `1920` 帧，帧表索引位宽为 `21` 位，单元位宽为 `7 + 1 = 8` 位。这还包含了以下隐藏信息:
- 该视频文件大小不（应）超过 6 （头部） + 1920 * 21 / 8 （帧表） + 2^21 * 8 / 8 （数据） = 2,102,198 Bytes。


### 帧表
帧表长度为 `帧数 * 帧表位宽` Bits。每个帧的起始单元计数信息占用 `帧表位宽` Bits，地址为 `起始单元计数 * 单元位宽 // 8` Bytes + `起始单元计数 * 单元位宽 % 8` Bits。

例：帧表位宽为 `5`，帧数为 `5`，单元位宽为 `4`，帧表可能的二进制表示如下：
```
00000 00111 10010 11010 11101
```
其十进制表示为：
```
0 7 18 26 29
```
这表示有如下对应关系：
| Frame | 起始单元计数 | 地址（Byte） | 地址（Bit） |
|:-----:|:-----------:|:------------:|:-----------:|
| 1 | 0  | 0x0  | 0  |
| 2 | 7  | 0x3  | 4  |
| 3 | 18 | 0x9  | 0  |
| 4 | 26 | 0xD  | 0  |
| 5 | 29 | 0xE  | 4  |

### 数据
数据由单元堆积而成。每个单元的长度为`单元位宽 + 1` Bits，其中第一个 Bit 为颜色位，后面的 Bits 为单元长度。每个单元的颜色位为 0 时表示黑色，为 1 时表示白色。每帧的单元长度加和应为 `宽`。

例：`单元位宽 = 7`，则每个单元的长度为 `8` Bits。一个单元可能的二进制表示如下：
```
00000001
```
这表示，该单元的颜色为黑色，长度为 `1` 像素。
